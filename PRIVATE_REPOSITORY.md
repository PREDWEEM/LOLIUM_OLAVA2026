# Repositorio privado

La aplicación debe desplegarse desde la rama `main` y el archivo `app_emergenciacombinado.py`.

Antes de cambiar la visibilidad, autorice a Streamlit para acceder a los repositorios privados de `PREDWEEM`.

Después del cambio:

1. Ejecute manualmente `Actualizacion Diaria Clima`.
2. Confirme la actualización de `meteo_daily.csv`.
3. Ejecute `Verificar despliegue privado`.
4. Compruebe la carga local de datos y modelos.

Las credenciales deben almacenarse en GitHub Actions o Streamlit Secrets, nunca en archivos versionados.
